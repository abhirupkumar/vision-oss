# Vision Documentation

Welcome to the documentation repository for **Vision**, an open-source web analytics platform focused on privacy and simplicity.

This site is built with Next.js and [Fumadocs](https://github.com/fuma-nama/fumadocs).

## Running Locally

To run the documentation site locally and preview your changes:

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 in your browser to see the documentation site.

## Project Structure

- `content/docs/`: Contains the Markdown (MDX) source files for all documentation pages.
- `app/`: Next.js application routing and layouts.
- `public/`: Static assets (images, icons).

## Contributing to Docs

We welcome contributions to the Vision documentation! Whether it's fixing a typo, updating guides, or writing new deployment tutorials, your help makes Vision better for everyone.

To contribute:
1. Fork this repository.
2. Make your changes in the `content/docs/` directory.
3. Submit a Pull Request.
