title: Realtime
---

Retrieve live analytics for active visitors on your website over the last 30 minutes.

**Endpoint**

```text
GET NEXT_PUBLIC_API_URL/realtime/:projectId
```

---

## GET NEXT_PUBLIC_API_URL/realtime/:projectId

Returns active visitors, current pages being viewed, countries, and live event activity.
