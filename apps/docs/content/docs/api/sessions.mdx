**Endpoints**

```text
GET NEXT_PUBLIC_API_URL/projects/:projectId/sessions
```

## GET NEXT_PUBLIC_API_URL/projects/:projectId/sessions/stats

Returns aggregate session statistics such as bounce rates, average visit duration, and pageviews per session.

---

## GET NEXT_PUBLIC_API_URL/projects/:projectId/sessions/weekly

Returns weekly session distribution patterns grouped by day-of-week and hour-of-day.

---

## GET NEXT_PUBLIC_API_URL/projects/:projectId/sessions/:sessionId

Returns details for an individual session by ID.

---

## GET NEXT_PUBLIC_API_URL/projects/:projectId/sessions/:sessionId/activity

Returns chronological page navigation and event activity within the specified session.

**Sample response**

## GET NEXT_PUBLIC_API_URL/projects/:projectId/sessions/:sessionId/data

Returns custom session data properties attached to the session via the tracking script or SDK.

---

## GET NEXT_PUBLIC_API_URL/projects/:projectId/session-data/properties

Returns all session property keys and summary statistics across the project.

---

## GET NEXT_PUBLIC_API_URL/projects/:projectId/session-data/values

Returns distinct values for a given session property key.

---

## Visitors Endpoints

- `GET NEXT_PUBLIC_API_URL/projects/:projectId/visitors`: List identified and anonymous visitors with profile details.
- `GET NEXT_PUBLIC_API_URL/projects/:projectId/visitors/:visitorId`: Fetch visitor profile information, distinct ID, first seen date, and traits.
- `GET NEXT_PUBLIC_API_URL/projects/:projectId/visitors/:visitorId/activity`: Retrieve the complete cross-session activity history for a specific visitor.
