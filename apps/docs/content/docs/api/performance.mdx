**Endpoint**

GET NEXT_PUBLIC_API_URL/projects/:projectId/performance

---

## GET NEXT_PUBLIC_API_URL/projects/:projectId/performance

Returns aggregated Core Web Vitals metrics, including Largest Contentful Paint (LCP), Interaction to Next Paint (INP), Cumulative Layout Shift (CLS), First Contentful Paint (FCP), and Time to First Byte (TTFB).

**Parameters**

| Parameter | Type   | Description                                 |
| --------- | ------ | ------------------------------------------- |
| `startAt` | number | Start timestamp in milliseconds.            |
| `endAt`   | number | End timestamp in milliseconds.              |
| `url`     | string | (optional) Filter performance by page URL.  |
| `device`  | string | (optional) Filter by device category.       |
| `country` | string | (optional) Filter by country code.          |

    "value": 920,
    "rating": "good",
    "p75": 1100
