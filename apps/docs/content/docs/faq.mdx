### 1. Is Vision GDPR compliant?

Yes, Vision does not collect any personally identifiable information and anonymizes all data collected. Users cannot be identified
and are never tracked across websites.

### 2. Do I need to display a cookie notice to users?

No, Vision does not use any cookies in the tracking code.

### 3. Does Vision work on a single page application (SPA)?

Yes, Vision automatically tracks page navigations in SPAs without any additional configuration.

### 4. Can Vision record events such as button clicks?

Yes, please see [Track Events](/docs/track-events) under **Getting Started**.

### 5. What data does Vision collect?

Vision collects page views, referrer URLs, browsers, operating systems, device types, and country of origin. All data is anonymized and no personally identifiable information is stored. See [Metric definitions](/docs/metric-definitions) for a full list.

### 6. What databases does Vision support?

Vision supports PostgreSQL and ClickHouse for high-throughput event storage and analytics.

### 7. How long is data retained?

Data is retained indefinitely according to your organization's plan settings unless manually deleted.
