---
title: Using organizations
---

Vision organizations allow you to group websites, users, and resources under a shared workspace for easier management and collaboration. This structure improves data governance, access control, and visibility.

## Roles

Organization roles and related permissions.

| Role                   | Permissions                                                    |
| ---------------------- | -------------------------------------------------------------- |
| Organization Owner     | All permissions.                                               |
| Organization Manager   | All permissions except deleting the organization.              |
| Organization Member    | All permissions except deleting or updating the organization.  |
| View Only              | View only access.                                              |

## Organization access

There are two methods to access an organization.

**Method 1:** Navigate to **Organizations** and click on the organization name under the **Name** column.

![image](/images/docs/team-view.png)

**Method 2:** Use the quick organization access dropdown from the Vision navbar.

![image](/images/docs/team-quick-access.png)
